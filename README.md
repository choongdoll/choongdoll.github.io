# Choong Yeon Kim — Personal Academic Website

Static academic website prepared for GitHub Pages.

## Publish at `https://choongdoll.github.io`

1. Create a public GitHub repository named exactly `choongdoll.github.io`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

## Main sections

- About and professional links
- Selected published research
- Selected publications
- Honors and fellowships
- Technical expertise
- Contact

## Editing

- Page content: `index.html`
- Design: `assets/styles.css`
- Mobile menu and animations: `assets/script.js`
- Images: `assets/images/`
